# The gated files of the mutation gate (#35; docs/decisions.md, "Mutation
# testing"). They hold the trust model: `decide()`, the log's chain and
# state, the canonical encoding, change ids, keys and paths, the auditor and
# the structural merge it recomputes. One path per line; a path ending in `/`
# covers everything under it.
#
# .github/workflows/mutants.yml mutates only these files, only what changed
# since the last release. A gated file must have no missed and no timed-out
# mutant, and every mutant `.cargo/mutants.toml`
# excludes in one must be listed, by name, in `mutants-gated-exclusions.txt`.
# `.github/scripts/mutants-gate.sh` checks both, also locally.
